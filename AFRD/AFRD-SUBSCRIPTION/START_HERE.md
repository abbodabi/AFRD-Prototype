# 🔍 Fake Review Detection - Subscription System

**Complete, Production-Ready Subscription Interface**

## 📦 What You Have

A fully functional web-based subscription management system for an online fake review detection service with two subscription tiers: 3-Day Trial ($2.99) and 1-Month Premium ($29.99).

## ⚡ Quick Start (2 minutes)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the application
python subscription.py

# 3. Open browser
# http://localhost:5000
```
